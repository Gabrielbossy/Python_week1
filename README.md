-# Python Week 1

My first week of learning Python: variables, strings, loops, lists, dictionaries and a terminal contact book.

## Contact Book

A command-line program that lets you add, view, search, edit and delete contacts. Contacts are saved to a file, so they are still there the next time you run it.

## How to run it

1. Install Python 3
2. Download this project
3. In a terminal, run: `python contacts.py`

## What I practised

- Variables, input and output
- if/else and loops
- Dictionaries
- Saving data to a JSON file
- try/except for error handling
